Mobile horizontal padding: 20–24px

Section spacing:
Desktop: 112px
Mobile: 64px

## Visual Principles

- Typography-first composition
- Generous whitespace
- Restrained accent color
- Subtle borders
- Minimal use of cards
- No skill progress bars
- No excessive animations
- No generic stock illustrations
- No large terminal UI
- No custom cursor

## Developer Aesthetic

Use small technical details:
- Monospace section labels
- Numbered section headings
- Subtle code-inspired elements

Decorative elements must never compete
with the professional content.

## Hero

Primary focus:
- Name
- Full Stack Software Engineer
- Value proposition
- Employment availability
- Work and resume actions

A small code-inspired decorative line
may appear below the main content.

## Accessibility

- WCAG AA contrast targets
- Visible keyboard focus
- Semantic headings
- Reduced motion preferences
- Responsive content hierarchy

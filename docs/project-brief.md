
# Leandro Portfolio — Project Brief

## Purpose

Build a professional presentation website for
Leandro Sanchez, a Full Stack Software Engineer
based in the Dominican Republic.

## Primary Goal

Attract employment opportunities, especially
remote and international software engineering roles.

## Secondary Goal

Present independent technology consulting experience.

## Professional Positioning

Full Stack Software Engineer.

Core technologies:
- React / Next.js
- TypeScript / JavaScript
- Node.js / NestJS
- C# / ASP.NET Core
- SQL Server / PostgreSQL
- n8n / AI integrations

## Design Direction

Dark Editorial Engineering.

80% editorial minimalism.
20% subtle developer-inspired visual details.

Dark mode is the default and only theme for V1.

## Architecture

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Static site generation
- English and Spanish
- Local content in TypeScript or MDX
- No database in V1
- No authentication or CMS
- Hosting: Vercel initially

## Site Structure

/en
/en/experience
/en/projects
/en/projects/[slug]
/en/about
/en/contact

Equivalent routes under /es.

## Primary Sections

1. Hero
2. Selected Work
3. Professional Experience
4. Technical Expertise
5. About
6. Contact

## Key Requirements

- Mobile-first responsive design
- Semantic HTML
- Accessible keyboard navigation
- SEO metadata
- Sitemap and robots.txt
- Structured data
- Excellent performance
- Minimal dependencies
- Reduced motion support

## Content Rules

Never invent professional experience,
certifications, achievements, metrics,
or project functionality.

Use real professional information only.
